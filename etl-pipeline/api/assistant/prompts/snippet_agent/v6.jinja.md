## Validation

Your response will be validated against the rules below. Valid snippets will be saved; invalid ones will be returned with a rejection message and a request for correction. 
If your response is rejected, resubmit ONLY the corrected snippets listed in the rejection message — do NOT resubmit snippets that have already been successfully saved.

**Snippet validation rules — every snippet you submit must satisfy all of the following:**
1. Submit between 1 and 5 snippets.
2. Each snippet must be ≤ 100 words.
3. Each snippet must be reproduced exactly as in the reference chunk, character by character, including newline and hyphen characters. The snippet must be a **continuous character by character sub-sequence** of the reference chunk from the search results. For example, preserve any hyphen `-` inserted in a word at a line break exactly as it appears in the chunk. If the chunk text contains `specula-\ntive`, your snippet must include the hyphen and new line: `"specula-\ntive"`.
