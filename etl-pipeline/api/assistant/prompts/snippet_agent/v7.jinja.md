## Your Task

## Validation

Your response will be validated against the rules below. Valid snippets will be saved; invalid ones will be returned with a rejection message and a request for correction. 
If your response is rejected, resubmit ONLY the corrected versions of the snippets listed in the rejection message — do NOT resubmit snippets that have already been successfully saved.

**Snippet validation rules — every snippet you submit must satisfy all of the following:**
1. Submit between 1 and 5 snippets.
2. Each snippet must be ≤ 100 words.
3. Each snippet must be an exact match to the reference chunk, including newline and hyphen characters, according to the snippet formatting rules.

**Formatting Rules**
* The snippet must be a **continuous character by character sub-sequence** of the reference chunk from the search results.
* Each snippet must source from a single chunk.
*  For example, preserve any hyphen `-` inserted in a word at a line break exactly as it appears in the chunk. If the chunk text contains `specula-\ntive`, your snippet must include the hyphen and new line: `"specula-\ntive"`.
* The one exception to an exact character by character sequence match are elisions. Snippets may use three periods `...` to elide characters from the source chunk.
* Use elision to skip page header or footer text (the book name, chapter name, page number, author name, etc...)
* Use elision skip irrelevant content from the source chunk and keep the snippet under the required max length.
* If elision is used, the snippet must faithfully convey the meaning of the source text.
