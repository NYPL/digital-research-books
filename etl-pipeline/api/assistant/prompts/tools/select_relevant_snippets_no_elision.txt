Validate, save, and record text excerpts relevant to the user's search interest.

Use this tool to select 1-5 representative text snippets per edition.
This tool validates the snippets you submit and saves valid ones to be displayed
alongside each book. Your goal is to submit valid snippets for every outstanding
edition ID. Do not stop until the tool responds with no resubmission requests (i.e.,
all editions are saved). When the tool requests resubmission, resubmit ONLY the
editions/snippets listed in the resubmission message — do NOT resubmit editions that
have already been successfully saved.

Args:
    snippets: List of edition snippet objects. Each object must contain:
        - ``edition_id`` (int): The edition ID that the snippets are taken from.
        - ``snippets`` (list): 1-5 snippet objects from that edition. Each snippet
          object must contain:
            - ``item_id`` (int): The item ID of the chunk that the snippet comes from.
            - ``snippet`` (str): The snippet text. The following rules apply:
              * Each snippet must be no more than 100 words.
              * Each snippet must be an exact verbatim substring of a chunk — copy
                the text directly from the chunk without any modification.
              * Snippets will be validated to make sure the snippet text appears as a
                literal substring in at least one chunk. For example: include any hyphen ``-`` characters inserted in words at a line break
                exactly as they appear in the chunk text. If the chunk
                contains ``specula-\ntive``, your snippet must preserve the hyphen:
                ``"specula-\ntive"``.
        Example:
            [
                {
                    "edition_id": 4872,
                    "snippets": [
                        {
                            "item_id": 9021,
                            "snippet": "the mitochondria is the powerhouse of the cell",
                        },
                        {
                            "item_id": 9021,
                            "snippet": "Cellular respiration begins in the cytoplasm and terminates with the synthesis of ATP.",
                        },
                    ],
                },
                {
                    "edition_id": 5310,
                    "snippets": [
                        {
                            "item_id": 9834,
                            "snippet": "Darwin observed that species adapted over genera-\ntions",
                        },
                    ],
                },
            ]
