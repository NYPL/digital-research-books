This folder contains 300 barcodes taken from the GRIN 10k experiment corpus. This is a sub sample to be used for evaluation tasks. The sub sample stratifies on a selection of subjects designed to represent a diversity of the content in the GRIN 10k. Individual subjects are oversampled in order to get enough content in each category to have multiple documents competing to provide the same information, while diverse subjects are chosen to include realistic irrelevant context to challenge the retriever mechanism.
